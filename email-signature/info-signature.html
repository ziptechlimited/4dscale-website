Where to paste it

Zoho Mail (web)
  1. Click Copy signature above.
  2. In Zoho Mail, open Settings (gear icon) → Signature → Add signature.
  3. Name it “4D-Scale”, click in the editor and paste (Cmd + V / Ctrl + V).
  4. Link it to info@4dscalelimited.com, set it to appear on new emails and replies, and Save.
Gmail (web), if you send as info@ from Gmail
  1. Gmail → gear icon → See all settings → General → Signature → Create new.
  2. Paste into the box, choose it under “Signature defaults” for info@4dscalelimited.com, then Save Changes at the bottom.
Apple Mail (Mac)
  1. Mail → Settings → Signatures → choose the info@ account → +.
  2. Untick “Always match my default message font”, paste the signature, close the window.
Phone apps (Gmail app, Zoho Mail app)

Mobile signature settings only accept plain text. Click Copy plain-text version, send it to your phone (e.g. WhatsApp it to yourself), then paste it into the app’s signature setting: Gmail app → Settings → your info@ account → Mobile signature.
